# imgpick2 — client image picks

The 38 photographs from the client's `D:\imgpick2` scratch folder, copied into the
project on 11 November 2026. Each file keeps its original name (`a1`–`a20`,
`b1`–`b8`, `c1`–`c10`) so it can be matched back to the contact sheets. The
originals are untouched; these copies are re-encoded to fit a 1600 px box at
JPEG quality 80 (≈3.6 MB total).

**Status:** reference library only — nothing here is imported by a component yet.
The live page still uses the curated files in `hero/`, `about/`, `properties/`,
`services/`, `collection/` and `cta/`. To use one, import it where it belongs and
delete the copy that is not needed, or ask for the swap.

`sheet1`–`sheet4.jpg` and the `fetch.mjs` / `sheet.mjs` helpers were not copied:
they are contact sheets and tooling, not assets.
